# Naming

The project is called **term-flashy**.

## Why

The name follows the `term-*` pattern and was chosen based on the
per-tab notification feature: when an application signals something,
the tab needs to "flash" or visually grab attention. The word "flash"
carries that meaning directly, and "flashy" reinforces the visual,
attention-grabbing side of the notification.

## Discarded alternatives

- Names tied to the GUI library used by the project (`term-phloem`,
  `term-sap`, `term-flux`), discarded because they'd couple the
  project name to an internal technical choice that may change later.
- Generic notification names (`term-alert`, `term-signal`,
  `term-ping`), discarded for sounding too plain or already widely
  used by other projects.
- `term-flash`, the shorter form, already exists as a GitHub
  repository (`lindekaer/term-flash`, a flashcards app). To avoid
  confusion in searches, the `term-flashy` variant was chosen instead.
